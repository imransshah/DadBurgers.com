# Career KB

`careerkb.therealdadburgers.com` (password). A searchable knowledge base of
desk cards, slideshows and references for a federal IT Director and Deputy
CIO. Claude writes the content; you review it.

## What's in it

| Type | Where it comes from | Viewer |
| --- | --- | --- |
| Desk card | `content/desk-cards/*.md` | One-page card, printable |
| Slideshow | `content/slideshows/*.md` | 16:9 deck: ←/→, **F** full screen, **N** notes, `?s=3` deep links |
| Article | `content/articles/*.md` | Long-form page |
| Reference | `../eo/public/data/` (Order of Operations) | Summary, "for you", actions, link back |

Search is client-side ([MiniSearch](https://github.com/lucaong/minisearch)):
fuzzy and prefix matching, titles and tags weighted above body text, with
type, domain, source and tag facets. Pins and recently viewed live in the
browser only.

## Ground rules

1. **No CUI, PII or non-public agency text, ever.** This is a personal
   Cloudflare account, not an authorized agency system, password or no
   password. Every file must declare `handling: public`, and the build fails
   on control or classification markings and SSN-shaped numbers.
2. **Drafts until reviewed.** Claude-written content starts as `status: draft`.
3. **Sources or a ⚑ Verify flag.** A source without a URL shows as "Verify".

## Adding content

See [`content/README.md`](content/README.md) for the front matter schema.
Drop a `.md` file in the right folder, push, and the workflow validates,
builds and deploys.

## Setup checklist

1. Repository secrets `CLOUDFLARE_API_TOKEN` / `CLOUDFLARE_ACCOUNT_ID` (shared
   with the other sites; see the root README).
2. Repository secret `CAREERKB_SITE_PASSWORD` (a long passphrase). Without it
   the worker answers 503: it fails closed. Changing it signs everyone out.
3. Push or run *Career KB* from Actions. The first deploy creates the
   `careerkb.therealdadburgers.com` DNS record and certificate.

## Local development

```sh
npm install
npm run dev                                   # content build + Vite (no password gate)
echo 'SITE_PASSWORD=test' > .dev.vars && npm run worker:dev   # full worker, gate on
npm run validate                              # content checks only
```

`public/data/kb.json` is generated by `scripts/build-content.mjs` and not
committed.
